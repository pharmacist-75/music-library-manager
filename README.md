# MP3Management

MP3Management is a Windows desktop application for managing MP3 file metadata.

The application provides a graphical user interface for editing audio metadata, including artist and track title information.

## Features

- View and edit MP3 metadata
- Manage artist and track title information
- Windows Forms user interface

## Technology

- Visual Basic .NET
- .NET Framework 4.8
- Windows Forms
- IdSharp for MP3 metadata handling

## Requirements

- Windows
- .NET Framework 4.8
- Visual Studio with .NET desktop development support

## Getting Started

1. Clone the repository.
2. Open `MP3Management.sln` in Visual Studio.
3. Restore the required dependencies.
4. Build and run the application.

## Development

The project is being prepared for modernization.

Planned technical improvements include:

- Migration from Visual Basic .NET to C#
- Migration from .NET Framework 4.8 to .NET 10
- Replacement of IdSharp project references with NuGet packages
- Improvements to code quality and test coverage

Future functional enhancements may include:

- Integration with MusicBrainz for metadata retrieval
- Album and cover art management
- Automatic organization of music files into artist and album directories
